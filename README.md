# 🗺️ Karta — интерактивные карты Ташкента

Две карты в одном статическом сайте (без бэкенда и без внешних CDN — все библиотеки лежат локально в `vendor/`):

## 1. Банкоматы Ташкента — `index.html`

**1 589 банкоматов** г. Ташкента от **25 банков** по открытым данным [Центрального банка РУз](https://cbu.uz) (скачано 10.10.2026).

- кластеризованные маркеры на карте;
- фильтры: банк, район города (12 районов), платёжные системы (Uzcard, Humo, Visa, Mastercard, UnionPay, Мир, Maestro);
- поиск по адресу и банку; список результатов с переходом к точке.

Данные: `atms.json` (получены из открытого реестра ЦБ РУз, раздел «Банкоматы»).

## 2. Людные места Ташкента — `spots.html`

**804 объекта** массового скопления людей с цветовой разметкой зданий/территорий и текстовыми подписями по центру:

| Слой | Объектов | Цвет |
|---|---|---|
| Рынки и базары | 120 | 🟥 розово-красный |
| Моллы и ТЦ | 79 | 🟪 фиолетовый |
| Станции метро | 50 | 🟩 зелёный |
| Супермаркеты | 555 | 🟦 бирюзовый |

Из них **181 объект** — с реальным контуром здания/территории. Дополнительно включаемый слой банкоматов для анализа покрытия.

Данные: `spots.json` (OpenStreetMap, запрос через Overpass API, октябрь 2026).

## Запуск

Сайт полностью статический. Любой способ:

```bash
# вариант 1 — просто открыть файл
open index.html

# вариант 2 — локальный сервер
python3 -m http.server 8080
# → http://localhost:8080
```

Для отображения картографических подложек нужен интернет (тайлы © OpenStreetMap).

## Структура

```
├── index.html      # карта банкоматов
├── spots.html      # людные места (рынки, моллы, метро, супермаркеты)
├── atms.json       # данные по банкоматам (ЦБ РУз)
├── spots.json      # людные места (OSM)
└── vendor/         # Leaflet 1.9.4 (локально, без CDN)
```
